💰 Personal Expense Tracker

A simple and interactive web-based application that helps users manage their personal finances by tracking income, monitoring expenses, setting budgets, and organizing financial records.

✨ Features

💵 Add and manage income and expense transactions
📂 Categorize transactions for better organization
📊 View total income, expenses, and available balance
🎯 Set personal budgets and monitor spending limits
📜 View complete transaction history
📤 Export financial data for external use and record-keeping
📈 Interactive dashboard for financial overview
🎨 Simple and user-friendly interface

💻 Technologies Used

HTML5

- Webpage structure
- Forms and input elements
- Semantic HTML elements

CSS3

- Styling and layout design
- Flexbox and Grid
- Responsive design
- Colors, animations, and transitions

JavaScript

- DOM manipulation
- Event handling
- Transaction management
- Budget calculation and tracking
- Income and expense calculations
- Data export functionality
- Dynamic content updates
- Conditional statements and functions
